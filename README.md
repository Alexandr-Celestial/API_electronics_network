# API_electronics_network
Веб-приложение с API-интерфейсом сети по продаже электроники

## Описание

Проект реализует иерархическую структуру сети поставщиков электроники с тремя уровнями: завод, 
розничная сеть и индивидуальный предприниматель. Каждый элемент сети содержит информацию о контактах, 
продуктах и задолженности.

API предоставляет CRUD операции для узлов сети и продуктов с поддержкой фильтрации и прав доступа.

## Стек
+ Python 3.8+
+ Django 3+
+ Django REST Framework 3.10+
+ PostgreSQL 10+
+ django-filter - для фильтрации API
+ psycopg2-binary - драйвер PostgreSQL

## Установка

1. Клонировать репозиторий:
    ```
    git clone https://github.com/Alexandr-Celestial/API_electronics_network.git
    cd API_electronics_network
    ```
2. Создать виртуальное окружение и активировать его:
    ```python -m venv venv```
3. Установить зависимости:
    ```pip install -r requirements.txt```
4. Применить миграции:
    ```python manage.py migrate```
5. Запустить сервер разработки:
    ```python manage.py runserver```

## Админ-панель

- URL: `/admin/`
- Вход осуществляется через пользователя с правами администратора.

В админке можно управлять узлами сети, продуктами, очищать задолженности.

## API

Базовый URL: API доступен по пути, подключённому в основном urls.py.

Доступные эндпоинты:

- `/networklinks/` — CRUD операции для узлов сети, фильтрация по стране.
- `/products/` — CRUD операции для продуктов.

Доступ к API имеют только активные пользователи.

## Тестирование

Для тестирования API можно использовать Postman или curl.
